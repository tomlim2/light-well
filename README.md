# 빛우물

물속 석실의 천창으로 햇빛 기둥이 쏟아지고, 그 빛 속을 금붕어 떼가 느리게 돈다. three.js(WebGL 2)와 직접 쓴 GLSL로 그린 실시간 장면.
모델 파일도 텍스처도 없다: 물고기는 코드로 만든 메시 하나를 40마리로 찍었고, 빛·커스틱·돌바닥은 전부 셰이더다.

https://tomlim2.github.io/light-well/

```bash
npm install
npm run dev
```

마우스를 움직이면 카메라가 그쪽으로 조금 기운다. 세로 화면에 맞춰 구도를 잡았고, 가로 화면에서는 양옆이 어둠으로 이어진다.

구조와 그리는 방법은 [MAP.md](MAP.md).

## 참고

X에 올라온 5초짜리 생성 영상(세로 720×1280)을 보고 같은 장면을 실시간으로 다시 만들어 본 연습작이다. 영상의 정지 화면을 겹쳐 놓고 구도·치수를 맞췄고, 그 외에는 전부 새로 만들었다.
