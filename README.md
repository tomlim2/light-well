# 빛우물

물속 석실의 천창으로 햇빛 기둥이 쏟아지고, 그 빛 속을 금붕어 떼가 느리게 돈다. three.js의 TSL(Three.js Shading Language)로 그린 실시간 장면.
WebGPU가 있는 브라우저에서는 WebGPU로, 없으면 WebGL 2로 그린다 (셰이더 한 벌로).
모델 파일도 텍스처도 없다: 물고기는 코드로 만든 메시 세 가지를 40마리로 찍었고, 떼의 움직임은 컴퓨트 셰이더가, 빛·커스틱·돌바닥은 전부 셰이더가 만든다.

https://tomlim2.github.io/light-well/

```bash
npm install
npm run dev
```

화면을 두드리면 그 자리에서 떼가 놀라 흩어졌다가 다시 모인다. 마우스를 움직이면 카메라가 그쪽으로 조금 기운다.
세로 화면에 맞춰 구도를 잡았고, 가로 화면에서는 양옆이 어둠으로 이어진다.

주소 뒤에 `?fish=5` 를 붙이면 떼가 다섯 배(200마리)가 되고, `?gl=1` 은 WebGL 2 로 강제한다.

구조와 그리는 방법은 [MAP.md](MAP.md).

## 참고

X에 올라온 5초짜리 생성 영상(세로 720×1280)을 보고 같은 장면을 실시간으로 다시 만들어 본 연습작이다. 영상의 정지 화면을 겹쳐 놓고 구도·치수를 맞췄고, 그 외에는 전부 새로 만들었다.
처음에는 WebGL 2 + GLSL 로 만들었고(v0.3), v0.4 에서 TSL 로 옮겨 적었다.
